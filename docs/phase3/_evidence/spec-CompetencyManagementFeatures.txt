Cross-Role / Shared Features 
These don't belong to one role exclusively but should exist system-wide: 
●​ Self-assessment portal (employee-facing, visible to Dept Head/HR) 
●​ Evidence repository — attach certifications, project work as proof of 
competency 
●​ Auto-recommended learning — system suggests courses/content based on 
identified gaps 
●​ Mobile access — for ratings, approvals, and dashboard viewing on the go 
●​ Notification center — assessment due dates, approval pending alerts 
(role-specific views)
