## 3. The tax rule (one rule, both sides, proven with the same vectors)

Tax is EXCLUSIVE (price + tax extra). In integer minor units: `minor = round_half_up(price * 10^decimals)`; `pctMilli = round_half_up(percentage * 1000)`; `taxMinor = floor((minor * pctMilli + 50000) / 100000)`; `totalMinor = minor + taxMinor`. PHP `App\Domain\Money\TaxCalculator::tax(string|float $price, string|float $percentage, int $decimals): array{subtotal, tax, total}` (floats rounded to `decimals`); TS `lib/money/tax.ts` `priceWithTax(price, percentage, decimals)` same result. Shared test vectors (price, percent, decimals) -> tax, total:
`1000, 18, 2 -> 180.00, 1180.00` | `999.99, 5, 2 -> 50.00, 1049.99` | `0, 18, 2 -> 0, 0` | `1500, 0, 2 -> 0, 1500` | `1, 12, 2 -> 0.12, 1.12` | `0.05, 5, 2 -> 0.00, 0.05` | `0.10, 5, 2 -> 0.01, 0.11` | `2499, 28, 2 -> 699.72, 3198.72` | `1000, 18, 0 -> 180, 1180` | `1050, 5, 0 -> 53, 1103` | `19.99, 7.5, 2 -> 1.50, 21.49` | `100, 12.5, 2 -> 12.50, 112.50`. A `null` percentage or a missing rate means tax 0 and no tax line. Money in answers is a JSON number rounded to the currency's decimals.
