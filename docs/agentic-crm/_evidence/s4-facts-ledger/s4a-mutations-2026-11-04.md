# S4a deliberate breakages (mutation proofs), 2026-11-04

Runner: `scratchpad/s4-mutations/run-mutations.cjs` (modelled on track Z's `run-mutations.cjs`): for each row it proves the find text occurs exactly ONCE in the file, runs the named tests as a green BASELINE first, breaks the code, runs the tests (`php vendor/phpunit/phpunit/phpunit --colors=never <files>`, one process at a time), records the tests that FAILED, restores the original bytes and compares them byte for byte. A mutation counts as killed only when at least one test reported failed (a parse error with no failed test would be "broken", not a kill).

**60 mutations, 59 killed, 1 not killed; every file restored byte-identical: yes.**

The one survivor, F05, is an EQUIVALENT mutant, on purpose: `FactWriter::writeThrough` protects a person's value twice (it does not try when the column it read is not blank, and its UPDATE is conditional on the column still being blank), so removing either guard alone changes nothing a caller can see. F06 removes the conditional write alone (killed by the test that types a value between the read and the write) and F06b removes BOTH guards (killed by five tests). A first run left S07 (the explicit non-http scheme message) alive because the older test only checked a message shared with the generic refusal; `test_an_address_with_any_other_scheme_is_refused_by_name` now pins it and S07 is killed. F06b, F17, A10 and A11 were added in a second run (S4b's request for `can.decide`, and the `retrieved_at` check); run 1 had 56 mutations (54 killed) and its raw output is in the scratchpad (`s4-mutations/out/`). The runner and the mutation list are in `scratchpad/s4-mutations/` (`run-mutations.cjs`, `mutations.cjs`); the same list is the way to re-prove any row.
