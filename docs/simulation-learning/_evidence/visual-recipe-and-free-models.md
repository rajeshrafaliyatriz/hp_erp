# Dilum's visual recipe (measured) and free models found for the first-wave scenes

Saved 2026-10-26 from the approved plan (the whole plan is in `_evidence/approved-plan-2026-10-26.md`). Claims are tagged verified, inferred or unverified in the source text.

**A10. Dilum's look, measured from the live Learn Arduino app (its CSS and scene chunk, 26 Oct 2026).** UI tokens: background #f6eddd (cream), deeper #efe3d1, sidebar #e9dcca, card #f9f2e5, code background #f8f0e3, lines #cec0ad and #e2d7c7, navy #18213d and #24304a for text and dark UI, ink #4f535b, muted #696d74, faint #ada293, primary accent teal #1aa3a1 with a deep teal #3f7f8e, code keyword blue #2a56a3, code function orange #c0652d. Fonts: Barlow (body), Barlow Semi Condensed (labels and headings), JetBrains Mono (code); both are SIL OFL 1.1 open fonts (checked on GitHub). Shape: corner radii of 7 to 11 px plus pills and circles; soft, low-opacity navy shadows (`0 4px 10px -6px #18213d99`, `0 1px 3px #18213d40`). Scene: categorical part colours teal #1aa3a1, amber #f0a53a, green #3fae6a, blue #3d6fc4, purple #8a63c9, red #d64a3a, orange #ee7f62 and #f08a2e, yellow #f2c23a, pink #e36fa5, dark #2f3547, brown #7a5034. Renderer: WebGL with antialiasing and a capped pixel ratio, ACES filmic tone mapping, an explicit output colour space, toon materials with gradient maps beside standard PBR materials, soft (PCF) shadow maps, exponential fog, hemisphere, directional, point and spot lights, orthographic and perspective cameras; no outline pass and no post-processing. UI layout (Appendix B): a left icon rail, a progress chip, a context card with "zoom to it", code and serial panels, a lesson carousel. This is the recipe to apply to downloaded models.

**Download check (2026-10-26), made with the owner's free Sketchfab account. The token was used for this session only and is stored nowhere.** The licence record of these models reads "CC Attribution: author must be credited; commercial use is allowed" (CC BY 4.0). All six shortlisted models are downloadable and the API returns signed download links (nothing was fetched). Real GLB sizes: Spellkaze server rack 2.2 MB (744 faces; glTF 7.7 MB), Osho server rack 12.6 MB (29.7k faces), RaynaudL control room 14.8 MB (only 370 faces: textures dominate), Inditrion sci-fi terminal toolkit 4.4 MB, Inditrion wall-mounted console 1.2 MB, TL-SF1005D network switch 1.8 MB. Lesson: a low face count does not mean a small file, so the restyle step (replace the original textures with the shared palette) and KTX2 compression come before any model is used.
